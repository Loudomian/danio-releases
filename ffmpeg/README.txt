danio's FFmpeg

A small, fully static build of FFmpeg (https://ffmpeg.org) with x264
(https://www.videolan.org/developers/x264.html) and zlib, made for danio
(https://danio.learnder.org): it encodes rendered frames into video
fragments and joins them. Only what danio uses is built in.

version 2 or later (COPYING.GPLv2). The sources and the build script are
published with each build, in ffmpeg-<version>-source.tar.gz, at
https://github.com/Loudomian/danio-releases/releases
